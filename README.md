# Premium Brand Site Starter

## Getting Started

1. Install dependencies:
   ```
   npm install
   ```

2. Run the development server:
   ```
   npm run dev
   ```

3. Build for production:
   ```
   npm run build
   npm start
   ```

4. Run accessibility test:
   ```
   npm install @axe-core/puppeteer puppeteer
   node a11y-test.js
   ```

## Deployment

- Deploy to Vercel, Netlify, or any Node.js host.
- Ensure all `[REPLACE]` content and Unsplash images are updated before launch.
